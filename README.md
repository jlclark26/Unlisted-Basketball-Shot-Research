# Basketball Shot Probability Modeling

A quantitative machine learning project exploring the prediction of basketball shot outcomes using spatial, contextual, and defensive features.

## Overview

The project focuses on building and evaluating probabilistic classification models, with emphasis on feature engineering, cross-season validation, gradient boosting, and probability calibration.

## Modeling Techniques

- Python-based data processing and feature engineering
- Logistic regression and gradient boosting
- LightGBM, XGBoost, and CatBoost
- Out-of-sample and cross-season validation
- Ensemble modeling and isotonic probability calibration
